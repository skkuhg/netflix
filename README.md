# Netflix Landing Page Clone

This project is a responsive replica of the Netflix landing page, built using pure HTML, CSS, and JavaScript. It demonstrates the layout, styling, and interactive elements of the original site, including the hero section, feature rows, and the FAQ accordion.

## Features

*   **Responsive Design:** Adapts to various screen sizes (Desktop, Tablet, Mobile).
*   **Interactive FAQ:** Custom JavaScript accordion for the Frequently Asked Questions section.
*   **Modern CSS:** Uses Flexbox and Grid for layout, CSS variables for theming, and gradients for visual overlays.
*   **Pure Vanilla:** No external frameworks or libraries required.

## Project Structure

*   `index.html`: The main HTML structure.
*   `style.css`: All styles, including responsive media queries.
*   `script.js`: Logic for the FAQ accordion interactions.

## How to Run

1.  Clone or download this repository.
2.  Open the `index.html` file in any modern web browser.
